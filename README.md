# 넘버 헌트 (Number Hunt)

브라우저에서 바로 실행되는 3D 3인칭 서바이벌 게임입니다. Three.js(r160)를 `vendor/`에 포함해 두었기 때문에 **빌드 과정 없이** 정적 파일만으로 동작합니다.

- 모든 캐릭터의 이마에 서로 다른 3자리 숫자가 있습니다. 얼굴 앞에서만 보입니다.
- 모두 근시입니다. 약 3m 안쪽은 선명하고, 8m 넘게 떨어지면 형태만 보입니다.
- 상대 번호를 입력하면 그 캐릭터가 탈락합니다. 없는 번호나 이미 탈락한 번호를 입력하면 5초 동안 입력할 수 없습니다.
- 벽에 얼굴을 묻으면 숨을 수 있지만 숨음 게이지가 가득 차면(30초) 탈락합니다.
- 마지막 1명이 남으면 승리합니다.

## 실행 / 배포

```bash
# 로컬 실행 (ES 모듈이라 file:// 로는 열리지 않음)
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages: 저장소 Settings → Pages → Branch에서 이 브랜치와 `/ (root)`를 선택하면 됩니다. `.nojekyll`이 포함되어 있습니다.

## 아이템

| 아이템 | 효과 |
|---|---|
| 🔭 망원경 | 8초 동안 1인칭 확대, 먼 거리도 선명하게 보임. 사용 중 이동 속도 절반 |
| 💥 섬광탄 | 약 6m 앞에 던짐. 반경 4m 안 캐릭터는 3초 경직되고 숫자가 빛나서 흐린 거리에서도 읽을 수 있음 |
| 📷 카메라 | 찍는 순간의 화면을 블러 없이 저장(3회). 사진은 확대해서 천천히 확인 가능 |

상자는 가까이 가면 자동으로 먹고, 30초 뒤 다시 생깁니다. 아이템은 한 번에 1개만 가질 수 있습니다.

  nav.js            봇 길찾기 (격자 A*)
  items.js          아이템 상자, 망원경/섬광탄/카메라 효과

### 근시 블러 동작 방식 (`vision.js`)

1. 씬을 깊이 텍스처와 함께 렌더 타깃에 그립니다.
2. 저해상도 가우시안 블러를 두 단계(중간, 강함)로 만듭니다.
3. 합성 셰이더가 깊이로 픽셀의 월드 좌표를 복원하고, **카메라가 아니라 내 캐릭터 눈**에서의 거리로 원본, 중간 블러, 강한 블러를 섞습니다.
4. 섬광탄으로 빛나는 숫자판은 알파 값을 0.5로 그려서 블러 대상에서 빠집니다.

품질은 `높음/중간/낮음/최저` 4단계입니다. 단계마다 픽셀 비율, 블러 해상도, 블러 반복 횟수, 그림자 사용 여부가 다릅니다. `자동`으로 두면 2초 평균 FPS가 32 밑으로 떨어질 때마다 한 단계씩 낮춥니다.

### 멀티플레이 확장 포인트

- `Character`는 스스로 판단하지 않고 `character.input`(이동, 바라볼 방향, 엎드리기)만 따릅니다. 로컬 플레이어(`LocalPlayerController`)와 봇(`BotController`)은 이 input을 채우는 컨트롤러일 뿐입니다. 원격 플레이어용 `RemoteController`를 같은 규약(`update(dt, now)`)으로 추가하면 됩니다.
- 판정은 모두 `Game`에 모여 있습니다(`submitGuess`, `eliminate`, `useItem`, 숨음 게이지). 서버나 호스트에서 이 함수들을 실행하고 이벤트(`eliminated`, `penalty`, `pickup`, `flash`, `end`)만 동기화하는 구조로 확장할 수 있습니다.

### 모델 교체

`js/models.js`의 `createCharacterModel`이 `{ root, body, head, plate, limbs }`를 반환하는 규약만 지키면 GLTF 모델로 바꿀 수 있습니다. 맵은 `map.js`에서 시각 메쉬만 교체하고 `colliders`/`occluders` 정의는 그대로 두면 됩니다.
